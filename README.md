# fc-clone-website

## 📌 About the Project

This project is a **Facebook Website Clone** created as part of my web development learning journey. I developed this project while following a tutorial to understand the basic concepts and workflow involved in building a modern website.

The main purpose of this project is to practice **HTML, CSS, and web development concepts** by creating a website inspired by the design and layout of Facebook.

## 🎯 Project Purpose

This project was created for learning and practice. It helped me understand how different web development concepts work together to create a user-friendly website interface.

Through this project, I practiced:

* Creating webpage layouts using HTML
* Styling webpages using CSS
* Designing navigation and content sections
* Working with images and other webpage elements
* Understanding website structure and organization
* Using Git and GitHub for version control

## 🛠️ Technologies Used

* CSS
* Git
* GitHub
